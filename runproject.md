## Setup Instructions

### 1. Create Credentials File

**Option A: Use .env file (RECOMMENDED)**

Create `.env` in the project root (generated by `python generate_token.py`):

```
KITE_API_KEY=your_zerodha_api_key
KITE_API_SECRET=your_zerodha_api_secret
KITE_ACCESS_TOKEN=your_zerodha_access_token
```

**Option B: Use credentials.json**

Create `credentials.json` in the project root:

```json
{
  "api_key": "your_zerodha_api_key",
  "api_secret": "your_zerodha_api_secret",
  "access_token": "your_zerodha_access_token"
}
```

**Option C: Environment Variables**

```bash
export ZERODHA_API_KEY=your_key
export ZERODHA_API_SECRET=your_secret
export ZERODHA_ACCESS_TOKEN=your_token
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Verify Universe

Ensure `config/universe.json` exists with sector/stock definitions.

### 4. Run

```bash
python main.py
```

## Key Concepts (from 04.concepts/)

### Trading Windows (IST):

- **09:15** - Market open
- **09:20-09:34** - Opening Range formation
- **09:35-10:05** - ORB playbook (Opening Range Breakout)
- **10:05-10:10** - Gap confirmation
- **10:10-14:05** - Main session
- **14:05** - Entry cutoff
- **15:05** - Force exit all positions

### VIX-Based Regime:

- **TRENDING** (0-25th percentile): HMA alignment required, larger sizes, aggressive
- **NEUTRAL** (25-75th percentile): Standard mode, balanced approach
- **MEAN_REVERT** (75-90th percentile): Tighter stops, reduced sizes, range trading
- **HALT** (>90th percentile): No new entries, kill switch active

### Signal Grades:

- **A+** (1.0x size) - HMA aligned, RVOL high, StochRSI confirming, sector leader
- **A** (0.85x size) - HMA aligned, RVOL normal, good setup
- **B** (0.60x size) - HMA pullback or consolidation, weaker confirmation
- **C** (0x size) - Do not take

### Risk Management:

- Base risk: **0.35% per trade**
- Max positions: **6 concurrent**
- Max per sector: **2 concurrent**
- Position limits apply per signal grade
- Drawdown breakers: -1% (warning), -2% (halt), -4.5% weekly (halt)
- Two-stage exits: 50% at 1.5R, trail remainder with Chandelier (3.0x ATR, 10-bar lookback)

## Troubleshooting

**"No credentials file found"**

- Create `credentials.json` with Zerodha API credentials
- Or set environment variables (see Setup)

**"No universe file found"**

- Ensure `config/universe.json` exists
- Check that it contains sector and stock definitions

**"ModuleNotFoundError"**

- Run `pip install -r requirements.txt`
- Verify Python 3.8+

**Dashboard not updating**

- Check network connection
- Verify Zerodha API access token is valid
- Try `--headless` mode to see console errors

**High slippage in paper mode**

- This is expected during high volatility (VIX > 20)
- Adjust in `config.py` SLIPPAGE section if needed

## Notes

- **Paper Mode**: All trades are simulated. No real money is at risk.
- **Live Mode**: Requires explicit confirmation. Will execute real trades.
- **Dashboard**: Shows real-time market data, sector rankings, active positions, signals, P&L, risk status.
- **Logging**: Default to console. Add `--log-file` to save to file.
- **Performance**: Typical resource usage <100MB RAM, <5% CPU during normal operation.
